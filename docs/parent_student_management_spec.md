# 학부모–자녀 관리 기능

## 목적

원장 또는 권한이 있는 직원이 가입 완료된 학부모와 학생을
수동으로 연결하고 연결 이력을 관리한다.

## 연결 권한

- DIRECTOR: 허용
- STAFF: linkParentStudent 권한이 있을 때 허용
- 그 외 역할: 거부

## 학부모 후보

- ACTIVE 사용자
- 온보딩 완료
- GUEST 또는 PARENT

## 학생 후보

- ENROLLED 학생
- 학생 로그인 계정 존재
- 사용자 상태 ACTIVE
- GUEST 또는 STUDENT
- 활성 학부모 연결 없음

## 관계

- 어머니
- 아버지
- 조부모
- 기타 보호자

## 연결 규칙

- 학생당 활성 학부모 1명
- 학부모당 여러 자녀 허용
- 연결 시 필요한 역할을 자동 부여
- 연결과 역할 변경은 하나의 트랜잭션으로 실행
- 감사 로그 기록

## 연결 해제

- 행을 삭제하지 않음
- endedAt, endedBy, endReason 기록
- 해제 사유 필수
- 역할은 자동 강등하지 않음
- 감사 로그 기록
